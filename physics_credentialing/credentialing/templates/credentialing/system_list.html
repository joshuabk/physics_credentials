How this works. On the Skills page, set a skill to “per Linac”, “per HDR Afterloader”, etc. That skill then shows one checkbox for every active system of that type on each physicist's checklist — e.g. “Daily QA” checked off separately on the TrueBeam and the Synergy. Skills left as a single checkbox are unaffected. Retiring a system hides its checkboxes but keeps the history; deleting it erases them.
